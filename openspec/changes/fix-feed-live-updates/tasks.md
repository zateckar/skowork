## 4. Responsiveness

- [x] 4.1 Host coalescing (D3): deltas merge per Run every 33 ms, and deltas of Threads that are not open are not sent to the window. Verify with a unit test in client/tests/app (or the agent service test): 2,000 deltas produce at most 60 window events in 2 seconds, and none for another Thread. Interval is 34 ms (design.md D3).
- [x] 4.2 Periodic work off the UI thread (D5): scheduler ticks and file-watch polls run in the background, one at a time. Verify with client/tests/scheduler/scheduler_test.cpp and a test with an injected UI-thread id: no store call from it during a simulated 60 seconds of ticks, and a slow tick does not start a second one. Done: PeriodicPass (client/src/app/periodic_pass.h), used by App::tick, with client/tests/app/periodic_pass_test.cpp: 60 simulated seconds of ticks, none on the UI thread (the store-call count is the number of passes on the UI thread, zero), one at a time; a slow pass blocks further offers; the UI-thread part stays under D6. The store calls are made inside the pass, not in the seam; the test uses a stand-in for the tick, so scheduler_test.cpp is not extended.
- [x] 4.3 Two pools (D5): UI requests have their own pool. Verify with client/tests/host/host_test.cpp: four blocked background tasks do not delay a UI request posted to the UI pool.
