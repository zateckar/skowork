# Spec Delta

## ADDED Requirements

### Requirement: Prepared Brief Presentation
Agenda preparation SHALL present its brief with the briefing Content template (client/work-inbox Content Templates): the key facts of the request, a status callout when the item is already answered, overdue or missing information, the brief with Citations, the draft as a message draft when the item calls for one, and what the user still has to supply. The prepared draft offered by Send draft SHALL be read from the message draft when there is one.

#### Scenario: Briefing with a draft
- **WHEN** preparation of "Reply to Lucie about the invoice" finishes
- **THEN** the Thread shows a briefing with who asked, the due date, the brief with Citations and a message draft, and Send draft is prefilled with that draft
